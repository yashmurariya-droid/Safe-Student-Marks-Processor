\# Safe Student Marks Processor



A beginner Python project that reads student records from a CSV file and safely processes their marks.



\## Features



\* Reads student names and marks from CSV

\* Calculates average marks

\* Identifies the highest-scoring student

\* Skips invalid marks and values outside the 0–100 range

\* Handles missing files and file permission errors



\## Technologies



\* Python

\* CSV module

\* Exception handling

\* Input validation



\## How to Run



1\. Install Python 3.

2\. Place `safe\_marks.py` and `students.csv` in the same folder.

3\. Run:



&#x20;  `python safe\_marks.py`



\## Project Level



Beginner



This project was created for Python learning and practice.
